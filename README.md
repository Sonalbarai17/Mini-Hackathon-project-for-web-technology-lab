# React + TypeScript version

This is a separate React + TypeScript version of the same shopping cart. It fetches products from DummyJSON and uses React state to add/remove products and calculate the total.

## Run it
1. Install Node.js (LTS) from https://nodejs.org if it is not installed.
2. Open a terminal in this `react-version` folder.
3. Run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.

The project uses Vite + React + TypeScript.
